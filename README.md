# Minimoda - App de Ropa Infantil

Práctica de **Desarrollo de Interfaces** (2.º DAM). Consiste en maquetar en Android Studio la pantalla de inicio de una tienda de ropa a partir de un prototipo de Figma.

## 🛠️ Aspectos Técnicos
- **IDE y Lenguaje:** Android Studio y Java (API 28).
- **Estructura:** Uso de *ViewBinding*, `ConstraintLayout` y `LinearLayout` para un diseño adaptativo.
- **Recursos:** Paleta centralizada (`colors.xml`), estilos tipográficos en `sp` y optimización de imágenes en formato **WebP**.

## 📂 Contenido del Proyecto
1. **A1 y A2:** Análisis de bloques y organización de capas en Figma.
2. **A3:** Ficha de especificaciones (colores, fuentes y medidas en dp/sp).
3. **A4, A5 y A6:** Implementación del layout (`activity_inicio.xml`), recursos base y assets optimizados.
4. **A7:** Reflexión personal sobre el proceso de desarrollo.
